## Host it yourself

You run two things.

- **The app**, once. Serves the interface and holds your hosts, repositories
  and credentials. Put it on a laptop or a server.
- **A worker**, on every machine that should run agents. Contains git, tmux and
  the agent itself.

A new install has one machine in its fleet — itself — so you can run sessions
before adding any others.

Requirements: Docker, the Compose plugin, and Node 20 or newer on each
machine you install onto.

- [How self-hosting works](/docs/self-hosting) — the architecture, and the
  shapes that work.
- [Install](/docs/self-hosting/app/install) — the two commands.

## Firetower Cloud

<Callout>Not available yet.</Callout>

The app runs for you: the interface, the scheduling and the credential store.
Nothing to install, nothing to upgrade.

Agents run wherever you choose.

- **Your own machines.** Connected the same way as today — the app reaches out
  to them over SSH.
- **Ours.** Machines in minutes, with nothing to provision.

Same application either way.
