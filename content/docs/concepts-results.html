From request to code

Task
The goal given to an agent. It can start as your request or an issue from a connected tracker.
Repository
The git project an agent works on. A workspace checks out working files from it.
Branch
A line of changes in git. A separate git-backed workspace gives work its own branch.
Pull / merge request
The reviewable change submitted to your git host. Your team reviews and merges it through its normal process.

Artifact versus preview

Artifact Preview
What it is A saved, versioned result A running service in a workspace
Example A report or website prototype The app the agent is building
What it depends on The stored artifact and its access policy The running service and its worker

An artifact is not the running application. A preview is not an archive. Save or export the outputs you need before ending the workspace.
