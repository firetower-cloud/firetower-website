Open Customize → Agent profiles. A profile saves an agent’s role, instructions and execution settings.

1. Ask an AI to create a profile

Choose New profile → Create with AI. Describe the job, the agent you want to use, and whether it can delegate. Firetower opens a new task with a profile-creation prompt.

Example request
Create a Firetower agent profile named Release captain.
Use Claude Code to coordinate a release and delegate review to Reviewer.
Follow our release runbook. Ask before publishing or deploying.

Send the request. When the agent finishes, return to Agent profiles and open the saved profile. You can also choose Write it myself to fill in the form directly.

2. Set its role and workspace

SettingWhat it does
NameThe name you select at launch or use when delegating.
DescriptionWhat the profile does and when another agent should choose it.
PlacementSame workspace shares the lead’s files and branch. Its own workspace creates a separate work area.
MachineWhere a delegated agent’s own workspace runs. Shown when you select Its own workspace.

3. Choose how it runs

SettingWhat it does
AgentThe coding agent that runs this profile, such as Claude Code or Codex.
SubscriptionThe connected account the agent uses.
ModelA specific model, or the engine’s default.
PermissionsHow the selected agent handles approval requests.
EffortThe reasoning effort, when supported by the agent.
SandboxThe execution boundary, when this control is offered by the selected agent.
DelegationOperator works alone. Manager can delegate.
Can delegate toChoose all accessible profiles or a selected set. Only shown for a Manager.

Available run controls depend on the selected agent. A setting left on Engine default uses that agent’s default.

4. Choose the skills it loads

SettingWhat it does
Your always-on skillsInclude the skills you normally load in every task.
This repository’s defaultsInclude your default skills for the repositories used by the task.
Counted forPreview the skill set for a repository; it does not assign that repository to the profile.
Always include theseAdd named skills to the enabled sources above.

These sources add together. Check the skill count and any budget or review warnings before saving.

5. Review instructions and save

SettingWhat it does
InstructionsThe working rules included in the agent’s prompt. For a Manager, explain when to use each delegate.
Who can use itOpen the permissions dialog for an existing profile.
Where it livesFor a new profile, choose your personal space or a shared directory.
DefaultUse this profile for new workspaces unless you select another.

Click Save changes. Running agents keep the profile they started with; the changes apply to future launches.
