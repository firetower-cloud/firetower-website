Open Customize → Skills. The library lists your skills, built-in skills and skills shared with you.

1. Create a skill with AI

Choose Add a skill → Create with AI. Describe a repeatable task and when the agent should use the skill.

Example request
Create a Firetower skill named release-notes.
Use it when preparing customer-facing release notes.
Group merged PRs into features, fixes and improvements.
Link each change to its PR. Ask before publishing.

Send the request, then return to the skill library to inspect the result. If it appears under Waiting for you, review its files and approve it before use.

2. Import an existing skill

Choose Add a skill → Upload a folder. Click Choose a folder, or drop the folder into the app. The folder must contain SKILL.md and any files it references.

3. Review before importing

Check the detected name, description and file list. Resolve any reported errors. When importing several skills, select only the ones you need.

Click Import skill. Nothing is imported until you confirm.

4. Find the skill in your library

Search for the skill by name. Open it to read its instructions and files, then select it in an agent profile or the workspace’s skills control.

Update a skill

Import the folder again. Firetower shows whether it is unchanged, a new version or a separate copy. You can also ask an agent to revise the skill.

Share a skill

Use the skill’s permissions control to grant access to a person or move it into a shared directory. Follow the illustrated sharing guide.

Check what an agent loads

Profile skills, always-on skills and repository defaults can combine. Review the final selection before starting work.
