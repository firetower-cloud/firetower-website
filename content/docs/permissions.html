Directory and resource access

Level Purpose
Viewer Read what the resource exposes to viewers
Editor Work with the resource; workspace access includes powerful tools such as the terminal
Admin Manage the directory and its access

Additional grants on a single resource are Viewer or Editor. Directory administration is a separate responsibility. The resource’s type determines its exact actions.

Company roles are different

Member and Admin are installation roles. They control organization administration. Viewer, Editor and directory Admin are resource permissions. Being an installation Admin does not make every private resource visible.

Workspace access is not conversation ownership

People can read shared workspace activity according to their access. The person who starts an agent owns that conversation and its actions, including messages, approvals and shipping. A colleague starts their own agent to work alongside it.

Verify access

After changing a team or directory grant, check with a member account. Test both the action you intend to allow and one you intend to restrict.
