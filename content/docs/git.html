Before you start

Use your own git-host account. If your company’s host is missing, ask an administrator to add it. The steps below show GitHub’s browser sign-in.

Screenshots show the desktop app with sample data.

1. Choose your git host

Open Repositories → Git hosts. Find your host and select Connect.

2. Approve the connection

Firetower opens your browser and shows a code. Enter it on the sign-in page and approve access to the organizations you need. Return to Firetower when you finish.

3. Confirm your identity

Wait for the host to show connected. Select Identity to review the name and email used for commits.

4. Find your repository

Open Repositories → All repositories. Find the repository you want to use. If it is missing, check your organization access on the git host.

Other sign-in methods

GitLab can use browser sign-in when the instance supports it. Gitea and Forgejo use personal access tokens. When Firetower asks for a token, use its provider link and follow the permissions shown, then paste the token and select Connect.
