Avant de commencer

Utilisez une machine distincte sous macOS, Linux ou Linux dans WSL2. Activez SSH et vérifiez que le plan de contrôle peut la joindre.

Préparez un compte SSH avec les accès aux fichiers et au réseau dont vos agents ont besoin. Utilisez une machine distincte du serveur du plan de contrôle.

Les captures montrent l’application de bureau avec des données d’exemple.

1. Ouvrir Machines

Dans l’application de bureau, sélectionnez Machines dans la barre latérale. Sélectionnez Add a machine pour ouvrir le formulaire de connexion.

2. Renseigner la machine

Dans le formulaire, saisissez l’adresse du worker, son compte SSH et un nom facile à reconnaître.

3. Autoriser la clé SSH de Firetower

Copiez la clé publique affichée dans l’application. Ajoutez-la au fichier ~/.ssh/authorized_keys du compte SSH, ou enregistrez-la auprès de votre fournisseur cloud.

Dépliez les instructions pour voir la commande à utiliser. Revenez dans l’application et sélectionnez Add it. Firetower vérifie la connexion SSH.

4. Installer le worker

Une fois la connexion SSH établie, sélectionnez Install the worker. Gardez l’application ouverte pendant l’installation du worker et sa reconnexion.

5. Installer vos agents

Choisissez les agents à installer sur cette machine. Sélectionnez Install Claude Code, Install Codex ou un autre agent disponible. Attendez l’apparition des coches, puis sélectionnez Done.

6. Vérifier que la machine est prête

Dépliez la ligne de la machine. Vérifiez la présence du statut Ready, des coches vertes pour SSH, le worker et les outils requis, ainsi que d’un agent installé sous Agents.

Si une vérification échoue, suivez les instructions affichées dans l’application, puis sélectionnez check again. Les paquets système nécessitant des droits administrateur doivent être installés par la personne qui gère le worker.

Pour continuer : connecter un compte d’agent.
