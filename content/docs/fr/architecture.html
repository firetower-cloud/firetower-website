Les composants d’une installation

Machine
Un ordinateur physique ou virtuel sur lequel vos agents travaillent. Une machine peut héberger plusieurs espaces de travail.
Worker
Le programme Firetower installé sur une machine. Il lance les agents et gère leurs fichiers de travail.
Plan de contrôle
Le serveur qui coordonne le travail et gère les comptes, les identifiants et les accès.
Application cliente
L’application de bureau ou mobile utilisée pour lancer les tâches et consulter les résultats.

Que se passe-t-il en cas de déconnexion ?

Événement Ce qui continue Ce qui devient temporairement indisponible
Vous fermez l’application Les agents déjà lancés sur un worker Le suivi en direct, jusqu’à votre reconnexion
Le plan de contrôle redémarre Les processus des agents déjà lancés sur les autres machines La coordination, les nouveaux lancements et les actions côté serveur
Une machine d’exécution s’arrête Le travail sur les autres machines Tous les processus de la machine arrêtée

Les agents s’exécutent sous tmux et peuvent continuer après la perte de connexion au plan de contrôle. Le travail d’une machine indisponible n’est pas transféré automatiquement vers une autre.

Où se trouvent les données de travail

Le plan de contrôle conserve l’état partagé et les identifiants. Chaque worker garde les fichiers de travail et exécute les outils avec les droits de son compte SSH. Utilisez une VM distincte si les tâches ne doivent pas partager l’accès à la machine hôte.

Une nouvelle installation est vide

L’installation du plan de contrôle ne crée pas de worker. Ajoutez une machine avant de lancer votre première tâche.
