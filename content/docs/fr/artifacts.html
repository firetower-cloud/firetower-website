Ouvrez Artifacts dans la barre latérale pour retrouver les pages et les autres résultats publiés par vos agents.

1. Ouvrir un livrable

Sélectionnez un livrable, par exemple Checkout flow. Il s’ouvre dans Firetower. Vous pouvez aussi l’ouvrir depuis la conversation de l’agent. Vérifiez la version à côté du titre avant de commencer la relecture.

2. Sélectionner un élément et rédiger une note

Cliquez sur Annotate, puis cliquez sur la partie de la page à modifier. Rédigez une demande précise dans la zone de note.

Cliquez sur Keep this note pour l’ajouter à vos commentaires en attente d’envoi. Répétez l’opération pour les autres modifications.

3. Envoyer les commentaires à un agent

Ouvrez Notes pour relire vos commentaires. Choisissez l’agent destinataire si le lecteur vous le demande, puis envoyez les notes. Lorsqu’une mise à jour est publiée, ouvrez la nouvelle version et vérifiez les modifications.

Partager le livrable

Utilisez le bouton de partage du livrable pour accorder un accès. Consultez Partager une ressource. Exportez une copie si vous souhaitez la conserver en dehors de Firetower.

Livrable ou aperçu ?

Un livrable est un résultat enregistré. Un aperçu est une application en cours d’exécution dans un espace de travail.
