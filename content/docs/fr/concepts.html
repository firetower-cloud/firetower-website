Trois distinctions à retenir

  • Un profil est une configuration enregistrée. Une session est un agent qui utilise cette configuration pour travailler.
  • Un espace de travail contient des fichiers. Un répertoire Firetower regroupe des ressources pour les partager.
  • Une équipe d’agents réalise le travail. Une équipe de l’entreprise regroupe des personnes pour gérer leurs accès.
