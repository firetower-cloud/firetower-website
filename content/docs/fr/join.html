Ouvrez l’application de bureau. Saisissez le domaine Firetower fourni par votre administrateur.

Avant de commencer

  • Demandez l’URL de Firetower et vos identifiants à un administrateur.
  • Connectez-vous au VPN de l’entreprise si l’installation est privée.
  • L’application de bureau est disponible sur macOS et Windows. Pour un accès mobile, utilisez iOS ou Android.

Se connecter depuis un ordinateur

  1. Ouvrez l’URL de Firetower dans un navigateur. Connectez-vous. Si un mot de passe temporaire vous a été fourni, remplacez-le lorsque l’application le demande.
  2. Téléchargez l’application de bureau depuis la page de téléchargement de votre installation. Choisissez macOS ou Windows. Installez l’application, puis ouvrez-la.
  3. Saisissez la même URL Firetower dans l’application. Connectez-vous avec votre propre compte.
  4. Vérifiez vos accès. Ouvrez Machines et vérifiez qu’une machine est disponible. Connectez un compte d’agent ou utilisez un compte partagé par votre équipe.
Résultat attendu

L’application affiche l’installation de votre entreprise. Il est normal que la liste des espaces de travail soit vide à la première connexion.

En cas de problème de connexion

Problème rencontré Points à vérifier
Serveur inaccessible Ouvrez la même URL dans un navigateur sur cet appareil. Vérifiez le VPN et le nom de domaine.
Connexion refusée Utilisez vos identifiants Firetower, pas ceux de GitHub ou de votre agent. Au besoin, demandez à un administrateur de réinitialiser votre mot de passe.
Aucune machine disponible Demandez l’accès à une machine partagée. Un administrateur doit ajouter un worker avant de pouvoir lancer des tâches.

Pour continuer : connecter un compte d’agent ou lancer votre première tâche .
