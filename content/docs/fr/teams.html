Commencez dans Customize → Agent profiles. Les équipes d’agents se configurent à travers les profils qui réalisent et délèguent le travail.

Créer les profils spécialisés

Créez un profil Operator pour chaque responsabilité. Une petite équipe peut réunir un développeur, un relecteur et un spécialiste des tests. Définissez les résultats attendus de chacun et les compétences nécessaires.

Créer le profil responsable

  1. Créez un profil Manager. Activez la délégation.
  2. Choisissez les profils auxquels il peut déléguer. Limitez la sélection aux profils utiles pour la tâche.
  3. Rédigez les instructions de coordination. Précisez quoi déléguer, quels résultats récupérer et quand vous demander une décision.
  4. Choisissez l’emplacement de chaque spécialiste. Les fichiers partagés conviennent à la relecture et aux modifications coordonnées ; les espaces distincts conviennent aux modifications indépendantes.
  5. Lancez une tâche avec le profil Manager. Suivez le travail délégué et les résultats transmis dans la conversation.
Exemple : instructions du responsable 
Réalise la modification demandée.
Demande à Reviewer d’examiner les modifications et à QA de vérifier le comportement.
Traite leurs remarques et résume les résultats.
Demande confirmation avant d’élargir le périmètre de la tâche.

Vérifier les résultats de l’équipe

Le responsable reçoit les résultats des spécialistes, mais vous restez chargé de vérifier les modifications et les demandes d’autorisation. Les branches distinctes peuvent nécessiter une intégration avant publication.

Deux sens pour le mot « équipe »

Une équipe d’agents regroupe des profils qui travaillent ensemble. Une équipe de l’entreprise regroupe des personnes pour gérer leurs droits d’accès. Gérez ses membres depuis le site d’administration.
