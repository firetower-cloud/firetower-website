Avant de commencer

Ajoutez un worker et installez l’agent souhaité. Préparez les identifiants de votre abonnement.

Les captures montrent l’application de bureau avec des données d’exemple.

1. Choisir votre agent

Ouvrez Customize → Agents. Dépliez l’agent, puis sélectionnez Connect an account. Si un compte est déjà connecté, sélectionnez Connect another account.

2. Se connecter à votre abonnement

Donnez un nom explicite à la connexion, par exemple Développement · Principal. Suivez la méthode de connexion indiquée pour votre agent.

Claude Code

Exécutez claude setup-token sur votre ordinateur. Connectez-vous au compte Claude souhaité, collez le jeton obtenu dans Firetower, puis sélectionnez Connect account.

Pour connecter Codex

Nommez le compte et sélectionnez Continue to sign in.

Ouvrez l’adresse de connexion affichée. Saisissez le code et autorisez l’accès avec le compte Codex souhaité. Revenez dans Firetower et attendez le message Account connected.

3. Choisir le compte par défaut

À l’étape Account connected, vérifiez l’identité du compte. Laissez Use by default for new work coché si vous souhaitez utiliser ce compte par défaut, puis sélectionnez Done.

4. Vérifier la connexion enregistrée

Le compte apparaît désormais sous l’agent. Vérifiez que son statut est Connected. Les nouvelles tâches peuvent utiliser ce compte ; les tâches en cours conservent leur compte actuel.

Pour continuer : configurer le basculement entre comptes ou partager un compte.
