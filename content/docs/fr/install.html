Avant de commencer

  • Préparez un serveur Linux avec un accès SSH et les droits root ou sudo.
  • Choisissez un nom de domaine, par exemple firetower.your-domain.com .
  • Prévoyez l’accès aux enregistrements DNS et un jeton API de votre fournisseur DNS.
  • Choisissez le mode d’accès de votre équipe au serveur : VPN maillé, réseau privé ou point d’accès public administré.

Consultez les prérequis avant de commencer.

1. Préparer l’accès privé

Connectez le serveur et votre ordinateur au même réseau privé. Pour Tailscale, exécutez :

Sur le serveur du plan de contrôle
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Ouvrez l’URL de connexion affichée dans le terminal pour rejoindre le réseau Tailscale de l’entreprise. Installez Tailscale sur votre ordinateur et rejoignez le même réseau.

Vérifiez que votre ordinateur peut joindre le serveur avant de poursuivre. Consultez le guide d’installation de Tailscale pour en savoir plus.

2. Lancer l’installation

Sur le serveur du plan de contrôle 
curl -fsSL https://usefiretower.com/install.sh | sh

Le script vérifie les prérequis, installe Docker et Node.js si nécessaire, installe la CLI Firetower, puis lance l’assistant d’installation.

3. Suivre l’assistant

  1. Choisissez le réseau. Confirmez l’adresse VPN détectée ou choisissez Advanced pour saisir une autre adresse accessible.
  2. Renseignez le domaine et les paramètres des certificats. Sélectionnez votre fournisseur DNS et saisissez son jeton API lorsqu’il vous est demandé.
  3. Créez les deux enregistrements DNS indiqués par l’assistant. Le nom de domaine sert à accéder à Firetower ; l’enregistrement générique sert aux aperçus.
  4. Choisissez le dossier d’installation et le nom de l’administrateur. Notez le chemin du dossier pour les opérations de maintenance.
  5. Vérifiez le récapitulatif et confirmez. Attendez le démarrage du déploiement. La première compilation du proxy peut prendre plusieurs minutes.
Exemple d’enregistrement Type Valeur
firetower.your-domain.com A L’adresse utilisée pour accéder à ce serveur
*.firetower.your-domain.com A La même adresse

Utilisez les valeurs exactes affichées par l’outil d’installation. Derrière un NAT, l’adresse utilisée par les clients peut différer de l’adresse locale sur laquelle le proxy écoute.

4. Se connecter

  1. Connectez-vous avec les identifiants administrateur affichés par l’outil d’installation. Ouvrez l’URL Firetower pour vous connecter.
  2. Sauvegardez la clé racine et la base de données. Conservez la clé racine séparément de la sauvegarde de la base, en dehors de ce serveur. Consultez Sauvegarder Firetower .
Un serveur prêt ne signifie pas que les agents sont prêts

Une nouvelle installation ne contient aucune machine d’exécution. Téléchargez l’application de bureau, connectez-la à cette URL, puis ajoutez votre première machine .

Si le DNS ou les certificats prennent du temps

Les modifications DNS peuvent mettre du temps à se propager. L’obtention du certificat HTTPS peut aussi prendre plusieurs minutes, le temps que l’autorité de certification valide votre domaine.

Laissez l’installation se poursuivre

N’arrêtez pas et ne relancez pas l’installation pendant l’attente du DNS ou des certificats. Les demandes de certificat sont réessayées automatiquement.

Des demandes de certificat échouées à répétition peuvent déclencher les limites de Let’s Encrypt . Évitez de relancer l’installation pour forcer une nouvelle tentative. Si un délai est indiqué, attendez qu’il soit écoulé.

Si l’attente se prolonge, contactez-nous en joignant le message affiché par l’outil d’installation. Nous vous aiderons à terminer la configuration.

Pour continuer : ajouter une machine d’exécution → connecter un compte d’agent → lancer une tâche .
