Commencez dans Workspaces → New workspace. Vous pouvez choisir un dépôt dès le départ ou commencer sans dépôt et ajouter du code plus tard.

1. Choisir d’utiliser ou non un dépôt

Pour une tâche de développement, sélectionnez Add a repository, puis choisissez un ou plusieurs dépôts. Modifiez la branche de départ si nécessaire. Vérifiez la machine avant d’envoyer votre tâche.

2. Commencer sans dépôt

Pour une recherche, un rapport ou un autre travail sur des fichiers, ne sélectionnez aucun dépôt. Le sélecteur indique No repository: a bare workspace with no code in it. Fermez le sélecteur et envoyez votre demande.

Vous disposez toujours d’un dossier de travail et du panneau Files. Téléchargez les fichiers ou dossiers pour en conserver une copie locale. La comparaison Git et la publication des modifications deviennent utiles après l’ajout d’un dépôt.

3. Ajouter un dépôt après le début du travail

Ouvrez le sélecteur de dépôts en haut de l’espace de travail. Il affiche les noms des dépôts actuels ou No repository. Choisissez Add a repository to this workspace.

Sélectionnez les dépôts et leurs branches de départ, puis cliquez sur Check in. Firetower les clone à côté des fichiers existants et indique leur emplacement à l’agent. Poursuivez dans la même conversation.

Partager l’espace, garder sa conversation

Les personnes ayant accès à l’espace de travail peuvent consulter le travail partagé. Chaque conversation appartient à la personne qui l’a lancée. Un collègue peut lancer son propre agent dans cet espace.

Conservez les résultats avant de terminer l’espace de travail

Terminer un espace de travail peut supprimer ses fichiers et ses conversations. Publiez le code ou exportez les fichiers à conserver.
