Avant de commencer

Utilisez votre propre compte sur la plateforme Git. Si celle de votre entreprise n’apparaît pas, demandez à un administrateur de l’ajouter. Les étapes ci-dessous présentent la connexion à GitHub dans le navigateur.

Les captures montrent l’application de bureau avec des données d’exemple.

1. Choisir votre plateforme Git

Ouvrez Repositories → Git hosts. Repérez votre plateforme et sélectionnez Connect.

2. Autoriser la connexion

Firetower ouvre votre navigateur et affiche un code. Saisissez-le sur la page de connexion et autorisez l’accès aux organisations nécessaires. Revenez ensuite dans Firetower.

3. Vérifier votre identité

Attendez que la plateforme affiche connected. Sélectionnez Identity pour vérifier le nom et l’adresse e-mail utilisés dans les commits.

4. Retrouver votre dépôt

Ouvrez Repositories → All repositories. Recherchez le dépôt souhaité. S’il n’apparaît pas, vérifiez vos accès à l’organisation sur la plateforme Git.

Autres méthodes de connexion

GitLab permet la connexion par navigateur si l’instance le prend en charge. Gitea et Forgejo utilisent des jetons d’accès personnels. Si Firetower demande un jeton, ouvrez le lien du fournisseur et accordez les droits indiqués. Collez ensuite le jeton et sélectionnez Connect.

Pour continuer : configurer un dépôt.
