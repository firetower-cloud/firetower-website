Ouvrez Customize → Agents et dépliez l’agent dont vous souhaitez partager l’abonnement.

Partager la connexion

  1. Connectez le compte et testez-le vous-même. Donnez-lui un nom reconnaissable.
  2. Cliquez sur le libellé d’accès de l’abonnement indiqué ci-dessus. Il affiche yours pour un abonnement personnel, ou le nom du répertoire s’il est partagé. Dans la fenêtre, ajoutez une personne ou choisissez Move into a directory….
  3. Accordez l’accès à l’équipe de l’entreprise. Vérifiez qu’un membre peut sélectionner le compte au lancement d’une tâche.
  4. Définissez ses règles d’utilisation. Précisez s’il peut figurer dans les listes de basculement et comment suivre sa consommation.

Consultez Partager une ressource pour les étapes de partage avec une personne ou un répertoire.

Comprendre le quota

Tous les utilisateurs de la connexion consomment le même quota du fournisseur. Le partage dans Firetower ne crée ni licence ni quota supplémentaire. Respectez les conditions de votre abonnement.

Gérer le compte dans la durée

La personne qui a connecté le compte contrôle les opérations sur ses identifiants, comme la reconnexion et la désactivation. Prévoyez la continuité avant son départ de l’organisation.

Le partage n’active pas le basculement

Chaque personne choisit les comptes de secours d’une exécution. L’accès à un compte partagé ne l’ajoute pas automatiquement à toutes les séquences de reprise.
