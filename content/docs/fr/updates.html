Ouvrez Updates depuis le menu du compte. Recherchez les mises à jour, puis mettez à jour le plan de contrôle, les workers et l’application, dans cet ordre.

Rechercher les mises à jour

Cliquez sur Check again pour actualiser les versions disponibles. La capture met ce bouton en évidence. Les numéros de version sont des exemples ; les vôtres dépendront des versions publiées.

Avant de poursuivre, lisez les notes de version et créez une sauvegarde. Conservez la clé racine correspondante et la configuration du déploiement.

1. Mettre à jour le plan de contrôle

Dans This Firetower, cliquez sur Upgrade to…. Le plan de mise à jour du plan de contrôle s’ouvre.

Vérifiez les modifications de fichiers proposées et les variables d’environnement requises. Conservez votre configuration personnalisée, sauf si vous souhaitez la remplacer. Cliquez ensuite sur Start the upgrade.

Suivez l’opération jusqu’à sa réussite et au retour du plan de contrôle. Résolvez toute erreur avant de mettre à jour les workers.

2. Mettre à jour les workers

Laissez les tâches en cours se terminer ou arrêtez-les après avoir conservé leurs résultats. Une mise à jour du worker redémarre son environnement d’exécution. N’interrompez pas un travail que vous souhaitez conserver.

Sélectionnez les machines à mettre à jour, puis cliquez sur Plan the update for…. Les workers sont mis à jour vers la version du plan de contrôle.

Laissez Wait until nothing is running coché. Cliquez sur Start the upgrade; Firetower attend que les workers sélectionnés soient inactifs. Si vous choisissez de ne pas attendre, les sessions concernées prendront fin.

Vérifiez que chaque worker sélectionné se reconnecte après la mise à jour.

3. Mettre à jour l’application

Dans l’application de bureau, repérez This app. Cliquez sur Update to… and relaunch. Enregistrez les messages non envoyés au préalable ; l’application va redémarrer.

Le bouton de mise à jour de l’application apparaît dans le client de bureau. Sur mobile, installez la mise à jour depuis votre canal de distribution habituel.
