Avant de commencer

Connectez votre plateforme Git. Préparez la commande d’installation de votre projet et les variables d’environnement nécessaires.

Les captures montrent l’application de bureau avec des données d’exemple.

1. Ouvrir le dépôt

Ouvrez Repositories → All repositories. Repérez le dépôt et sélectionnez sa ligne pour afficher les paramètres.

2. Enregistrer la commande de préparation

Saisissez la commande dans Setup script. Elle s’exécute après la récupération des fichiers et avant le lancement de l’agent. Par exemple : pnpm install --frozen-lockfile.

Si le projet nécessite un fichier d’environnement, saisissez un chemin relatif, par exemple .env. Sélectionnez Save.

3. Ajouter les variables d’environnement

Dans Environment, saisissez le nom et la valeur d’une variable, puis sélectionnez Add. Répétez l’opération pour chaque variable nécessaire.

4. Vérifier la configuration enregistrée

Les noms des variables enregistrées apparaissent dans Environment; leurs valeurs restent masquées. N’ajoutez pas le fichier d’environnement à Git.

Créez un nouvel espace de travail pour appliquer ces paramètres. Si la préparation échoue, consultez sa sortie, puis corrigez la commande ou installez les outils manquants sur le worker.
