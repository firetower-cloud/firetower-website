Ouvrez Updates depuis le menu du compte, avec les droits administrateur. Vous pouvez sauvegarder la base de données directement depuis l’application.

1. Créer une sauvegarde

Cliquez sur Back up now sous la liste Machines. Gardez la page ouverte pendant l’affichage de Backing up….

2. Vérifier son achèvement

Le bouton affiche Backed up lorsque l’opération réussit. Le fichier de sauvegarde est enregistré sur le serveur ; il n’est pas téléchargé sur votre appareil.

3. Conserver les autres éléments de restauration

La sauvegarde depuis l’application contient le schéma public de la base de données. Conservez également les éléments suivants :

ParamètreFonction
Clé racine correspondanteNécessaire pour déchiffrer les identifiants enregistrés. Conservez une copie protégée séparément de la sauvegarde de la base.
Configuration du déploiementVos domaines, paramètres d’environnement et configuration des services.
Fichiers des workersLes modifications non commitées et les résultats hors Git à conserver. Ils ne figurent pas dans la base du serveur.

Le serveur conserve les dix sauvegardes les plus récentes. Gardez des copies hors du serveur selon la politique de conservation de votre équipe.

Tester la restauration

Testez tous les éléments de restauration dans un environnement isolé. Consultez Restaurer une installation.
