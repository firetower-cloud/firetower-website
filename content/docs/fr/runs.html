Ouvrez un espace de travail pour lire la conversation de l’agent. Utilisez le panneau Overview pour suivre l’équipe chargée de la tâche.

1. Suivre la conversation du responsable

Consultez l’avancement, les appels d’outils et les questions. Envoyez un message pour préciser la tâche ou réorienter le travail. Examinez les demandes d’autorisation avant de les approuver.

2. Ouvrir un agent ou un sous-espace de travail

Dans Overview → Team, cliquez sur l’agent à suivre. Par exemple, sélectionnez Quota band thresholds pour ouvrir la revue déléguée.

Vous voyez désormais les messages et les questions de cet agent. Les agents d’un même espace partagent ses fichiers ; ceux qui disposent d’un sous-espace ont leurs propres fichiers de travail. Le panneau Team permet de retrouver le responsable et les autres agents.

3. Revenir au responsable

Cliquez sur le nom du responsable dans le panneau Team ou sur le lien from au-dessus de la conversation déléguée. Consultez la synthèse du responsable une fois les résultats reçus.

Poursuivre depuis un autre appareil

Connectez-vous à la même installation Firetower et ouvrez l’espace de travail. Fermer une application cliente n’arrête pas les tâches, sauf si cet appareil héberge aussi le worker. Gardez le worker allumé.

Changer de compte

Utilisez le sélecteur de compte de l’espace de travail pour changer de compte. Consultez le guide du basculement entre comptes pour comprendre la différence entre poursuivre avec le même agent et transmettre le travail à un autre.

Terminer le travail

Vérifiez les résultats, publiez les modifications ou exportez les fichiers avant de terminer l’espace de travail. Arrêter un agent et supprimer son espace sont deux actions différentes ; lisez la confirmation avant de poursuivre.
