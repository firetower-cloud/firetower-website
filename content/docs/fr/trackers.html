Avant de commencer

Les tickets d’une plateforme Git connectée ne nécessitent pas de jeton supplémentaire. Pour Linear, créez une clé API personnelle dans ses paramètres API. Les étapes ci-dessous présentent Linear.

Les captures montrent l’application de bureau avec des données d’exemple.

1. Connecter l’outil de suivi

Ouvrez Tasks → Trackers. Collez votre clé Linear dans API key, puis sélectionnez Connect. Le lien get one ouvre les paramètres des clés Linear.

2. Vérifier la connexion

Attendez le statut connected. Firetower affiche les équipes accessibles avec cette clé. En cas d’échec, vérifiez que la clé est valide et qu’elle donne accès à l’espace Linear souhaité.

3. Choisir un ticket

Revenez dans Tasks. Choisissez Linear dans le sélecteur d’outil de suivi, puis filtrez la liste par équipe ou par statut. Sélectionnez Start à côté d’un ticket.

4. Vérifier et lancer la tâche

Firetower reprend le contexte du ticket. Choisissez le dépôt, la machine d’exécution et le profil d’agent. Ajustez la demande si nécessaire, puis lancez la tâche avec le bouton d’envoi.

Une tâche lancée depuis un ticket conserve son lien d’origine. La mise à jour du statut dépend de l’intégration Git de votre outil de suivi et du fonctionnement de votre équipe.
