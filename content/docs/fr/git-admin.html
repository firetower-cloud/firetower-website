Avant de commencer

Vous devez disposer des droits administrateur dans Firetower et de l’URL de l’instance Git de l’entreprise. Pour la connexion par navigateur, vous devez aussi pouvoir y enregistrer une application OAuth.

Les captures montrent l’application de bureau avec des données d’exemple.

Ouvrez Repositories → Git hosts dans l’application de bureau. Le bouton Add a host lance la configuration.

1. Choisir le fournisseur

Ouvrez Repositories → Git hosts → Add a host. Choisissez votre fournisseur. Pour une instance privée, sélectionnez l’option d’auto-hébergement correspondante.

2. Définir l’adresse et la méthode de connexion

Saisissez l’URL de l’instance. Firetower la vérifie et affiche la méthode de connexion disponible. Donnez-lui un nom reconnaissable par votre équipe.

Pour la connexion par navigateur, enregistrez une application OAuth en suivant les instructions affichées. Collez son identifiant client ou d’application. Si vous ne pouvez pas en créer une, choisissez l’option par jeton ; chaque personne se connectera avec son propre jeton.

3. Ajouter la plateforme

Sélectionnez Add the host. L’instance apparaît dans Git hosts. Firetower peut alors vous proposer de connecter votre compte personnel.

Chaque membre de l’équipe peut désormais sélectionner Connect et se connecter avec sa propre identité. Ajouter une plateforme ne donne pas accès à ses dépôts.

Pour continuer : connecter votre compte Git.
