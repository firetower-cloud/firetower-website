Avant de commencer

Connectez au moins deux comptes auxquels vous avez accès. Ouvrez l’exécution pour laquelle vous souhaitez configurer le basculement.

Les captures montrent l’application de bureau avec des données d’exemple.

1. Ouvrir les paramètres de basculement

Sous la zone de message, sélectionnez on limit: ask me.

2. Définir l’ordre des comptes

Activez Switch automatically, in this order. Sélectionnez le premier compte de secours, puis le suivant. Les numéros indiquent l’ordre dans lequel Firetower les essaiera.

Un compte de secours pour le même agent reprend sa conversation. Un autre agent démarre une nouvelle conversation avec la tâche et l’avancement transmis, en conservant les mêmes fichiers de travail.

3. Enregistrer la liste

Sélectionnez Save. Le bouton affiche désormais on limit: switch. Sélectionnez-le à nouveau pour consulter ou modifier la liste.

Lorsque la limite est atteinte

Lorsque l’agent signale que son quota est épuisé, Firetower essaie les comptes sélectionnés dans l’ordre. Les limitations temporaires de débit et les erreurs de connexion ne déclenchent pas de basculement.

Chaque compte n’est essayé qu’une fois par séquence de reprise. Si le basculement échoue ou qu’aucun compte ne reste disponible, ouvrez l’exécution pour choisir le compte suivant. Les comptes utilisant une clé API sont facturés à l’usage par leur fournisseur.
