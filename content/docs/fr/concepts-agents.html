Agent, modèle et compte

Agent / harness
Le logiciel qui utilise un modèle et des outils pour réaliser des tâches, comme Claude Code ou Codex. Le harness gère la conversation et l’exécution des outils.
Modèle
Le modèle d’IA utilisé par l’agent. Les modèles et réglages disponibles dépendent de l’agent choisi.
Compte d’agent
L’abonnement ou l’identifiant API connecté qui autorise l’utilisation du service. Partager un compte revient à partager son quota.

Profil, compétence et équipe

Profil d’agent
Des instructions et des réglages enregistrés pour un rôle, par exemple relecteur de code. Le profil peut définir l’agent, le compte, les compétences et les paramètres d’exécution.
Compétence
Des instructions réutilisables et des fichiers utiles pour une tâche précise. Par exemple, plusieurs profils peuvent utiliser la même liste de vérification du code.
Équipe d’agents
Un responsable et les profils spécialisés auxquels il peut déléguer. Un Manager peut déléguer ; un Operator réalise le travail qui lui est confié.

Les profils et les compétences sont facultatifs. Un profil définit le rôle ; une compétence fournit une méthode réutilisable. Ils ne deviennent un agent actif qu’au lancement d’une tâche.
