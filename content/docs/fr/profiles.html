Ouvrez Customize → Agent profiles. Un profil enregistre le rôle, les instructions et les paramètres d’exécution d’un agent.

1. Demander à une IA de créer un profil

Choisissez New profile → Create with AI. Décrivez le rôle, l’agent à utiliser et sa possibilité de déléguer. Firetower ouvre une nouvelle tâche avec une consigne de création de profil.

Exemple de demande
Crée un profil d’agent Firetower nommé Release captain.
Utilise Claude Code pour coordonner une livraison et délègue la revue à Reviewer.
Suis notre procédure de livraison. Demande confirmation avant de publier ou de déployer.

Envoyez la demande. Une fois le travail de l’agent terminé, revenez dans Agent profiles et ouvrez le profil enregistré. Vous pouvez aussi choisir Write it myself pour remplir directement le formulaire.

2. Définir son rôle et son espace de travail

ParamètreFonction
Name (nom)Le nom à sélectionner au lancement ou à utiliser pour déléguer.
DescriptionLe rôle du profil et les situations dans lesquelles un autre agent doit le choisir.
Placement (emplacement)Same workspace partage les fichiers et la branche du responsable. Its own workspace crée un espace de travail distinct.
MachineLa machine sur laquelle s’exécute l’espace propre à l’agent délégué. Ce réglage apparaît lorsque vous sélectionnez Its own workspace.

3. Choisir ses paramètres d’exécution

ParamètreFonction
AgentL’agent de développement qui utilise ce profil, par exemple Claude Code ou Codex.
Subscription (abonnement)Le compte connecté utilisé par l’agent.
Model (modèle)Un modèle précis ou celui choisi par défaut par l’agent.
Permissions (autorisations)La façon dont l’agent gère les demandes d’autorisation.
EffortLe niveau de raisonnement, lorsque l’agent le prend en charge.
Sandbox (environnement isolé)Les limites de l’environnement d’exécution, lorsque ce réglage est proposé par l’agent.
Delegation (délégation)Operator travaille seul. Manager peut déléguer.
Can delegate to (profils autorisés)Autorisez tous les profils accessibles ou seulement certains. Ce réglage n’apparaît que pour un Manager.

Les réglages disponibles dépendent de l’agent choisi. Un paramètre laissé sur Engine default utilise la valeur par défaut de cet agent.

4. Choisir ses compétences

ParamètreFonction
Your always-on skillsInclure les compétences que vous chargez habituellement pour chaque tâche.
This repository’s defaultsInclure vos compétences par défaut pour les dépôts utilisés par la tâche.
Counted forPrévisualiser les compétences pour un dépôt, sans associer ce dépôt au profil.
Always include theseAjouter des compétences précises aux sources activées ci-dessus.

Ces sources se cumulent. Vérifiez le nombre de compétences et les éventuels avertissements de budget ou de validation avant d’enregistrer.

5. Vérifier les instructions et enregistrer

ParamètreFonction
InstructionsLes règles de travail incluses dans la consigne de l’agent. Pour un Manager, précisez quand utiliser chaque profil délégué.
Who can use itOuvrir la fenêtre des autorisations d’un profil existant.
Where it livesPour un nouveau profil, choisir l’espace personnel ou un répertoire partagé.
Default (par défaut)Utiliser ce profil pour les nouveaux espaces de travail, sauf si vous en choisissez un autre.

Cliquez sur Save changes. Les agents en cours conservent le profil utilisé au démarrage. Les modifications s’appliquent aux prochains lancements.

Pour continuer : créer une équipe d’agents ou partager le profil.
