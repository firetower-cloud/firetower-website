Ouvrez Customize → Skills. La bibliothèque rassemble vos compétences, celles intégrées à Firetower et celles partagées avec vous.

1. Créer une compétence avec l’IA

Choisissez Add a skill → Create with AI. Décrivez une tâche récurrente et indiquez quand l’agent doit utiliser cette compétence.

Exemple de demande
Crée une compétence Firetower nommée release-notes.
Utilise-la pour préparer les notes de version destinées aux clients.
Classe les PR fusionnées en fonctionnalités, corrections et améliorations.
Ajoute un lien vers la PR de chaque modification. Demande confirmation avant de publier.

Envoyez la demande, puis revenez dans la bibliothèque pour examiner le résultat. Si la compétence apparaît sous Waiting for you, vérifiez ses fichiers et approuvez-la avant de l’utiliser.

2. Importer une compétence existante

Choisissez Add a skill → Upload a folder. Cliquez sur Choose a folder, ou déposez le dossier dans l’application. Il doit contenir SKILL.md et les fichiers auxquels il fait référence.

3. Vérifier avant d’importer

Vérifiez le nom, la description et la liste des fichiers détectés. Corrigez les erreurs signalées. Si vous importez plusieurs compétences, sélectionnez uniquement celles dont vous avez besoin.

Cliquez sur Import skill. Rien n’est importé avant votre confirmation.

4. Retrouver la compétence dans votre bibliothèque

Recherchez la compétence par son nom. Ouvrez-la pour lire ses instructions et ses fichiers, puis sélectionnez-la dans un profil d’agent ou dans le sélecteur de compétences de l’espace de travail.

Mettre à jour une compétence

Importez à nouveau le dossier. Firetower indique s’il est inchangé, s’il s’agit d’une nouvelle version ou d’une copie distincte. Vous pouvez aussi demander à un agent de modifier la compétence.

Partager une compétence

Utilisez les autorisations de la compétence pour donner accès à une personne ou la déplacer dans un répertoire partagé. Suivez le guide de partage illustré.

Vérifier les compétences chargées par l’agent

Les compétences du profil, les compétences toujours actives et les réglages par défaut des dépôts peuvent se cumuler. Vérifiez la sélection finale avant de lancer la tâche.
