Accès aux répertoires et aux ressources

Niveau Rôle
Viewer (lecture) Consulter les informations visibles pour les lecteurs
Editor (modification) Utiliser la ressource ; dans un espace de travail, cela inclut des outils puissants comme le terminal
Admin (administration) Gérer le répertoire et ses accès

Les droits supplémentaires accordés sur une ressource sont Viewer ou Editor. L’administration du répertoire est une responsabilité distincte. Les actions possibles dépendent du type de ressource.

Les rôles dans l’entreprise sont distincts

Member et Admin sont des rôles au niveau de l’installation. Ils concernent l’administration de l’organisation. Viewer, Editor et Directory Admin définissent les droits sur les ressources. Être administrateur de l’installation ne rend pas visibles toutes les ressources privées.

L’accès à l’espace ne donne pas le contrôle des conversations

Les personnes peuvent consulter l’activité d’un espace partagé selon leurs droits. La personne qui lance un agent contrôle sa conversation et ses actions : messages, autorisations et publication. Un collègue peut lancer son propre agent pour travailler à ses côtés.

Vérifier les accès

Après avoir modifié les droits d’une équipe ou d’un répertoire, vérifiez le résultat avec un compte membre. Testez une action que vous souhaitez autoriser et une autre que vous souhaitez restreindre.
