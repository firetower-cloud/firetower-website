Open Workspaces in the desktop app. Use the composer to start a task.

Before you start

  • An online machine you can use.
  • A connected agent account, or access to a shared account.
  • Access to a repository for a coding task. You can also work without a repository .

Start the work

  1. Open the new-work composer. Choose the repository and a machine.
  2. Choose an agent and account. Use a profile if your team has already created one. Check the model and permission settings.
  3. Give it a bounded task. State the result you want and how it should check its work.
  4. Start the task. Read the conversation and answer permission requests as they appear.
Example prompt 
Find one unclear error message in this repository.
Improve the wording without changing behavior.
Run the relevant checks and summarize the change.

Check the result

  • Review the changed files and the agent’s test results.
  • Ask for revisions in the same conversation.
  • Open a pull request or merge request when you are ready. Review and merge through your normal process.
Keep running

Closing the client does not stop the agent. The worker machine must stay awake and connected to the services the task needs.
