Start from Workspaces → New workspace. You can begin with a repository, or leave it empty and add code later.

1. Choose whether to use a repository

For coding work, select Add a repository, then choose one or more repositories. Select its branch if you need a different starting point. Check the machine before sending your task.

2. Start without a repository

For research, reports or other file-based work, leave every repository unselected. The picker confirms No repository: a bare workspace with no code in it. Close the picker and send your request.

You still get a working directory and the Files panel. Download individual files or folders when you need a local copy. Git diff and shipping become useful once you add a repository.

3. Add a repository after work has started

Open the repository control at the top of the workspace. It shows the current repository names, or No repository. Choose Add a repository to this workspace.

Select the repositories and their starting branches, then click Check in. Firetower clones them beside the existing files and tells the agent where they are. Continue in the same conversation.

Share the place, own the conversation

People with workspace access can inspect shared work. Each agent conversation belongs to its initiator. A colleague can start their own agent in the workspace.

Save outputs before ending the workspace

Ending a workspace can remove its working files and conversations. Ship code or export files you need to keep.
