Before you start

Connect at least two accounts you can use. Open the run whose fallback you want to configure.

Screenshots show the desktop app with sample data.

1. Open fallback settings

Below the message box, select on limit: ask me.

2. Choose accounts in order

Enable Switch automatically, in this order. Select your first backup, then the next. The numbers show the order Firetower will try.

A backup for the same agent resumes its conversation. Selecting a different agent starts a new conversation with the task and progress so far, using the same workspace files.

3. Save the fallback list

Select Save. The control changes to on limit: switch. Select it again whenever you want to review or change the list.

What happens at the limit

When the agent reports that its usage allowance is exhausted, Firetower tries the selected accounts in order. Temporary throttling and sign-in errors do not trigger a switch.

Each target is tried once per recovery chain. If a switch fails or no target remains, open the run to choose the next account. API-key accounts use their provider’s usage billing.
