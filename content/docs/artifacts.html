Open Artifacts in the sidebar to find pages and other results your agents have published.

1. Open an artifact

Select an artifact, such as Checkout flow. It opens inside Firetower. You can also open it from the agent’s conversation. Check the version next to the title before reviewing.

2. Select an element and write a note

Click Annotate, then click the part of the page you want changed. Write a specific request in the note box.

Click Keep this note to add it to your draft feedback. Repeat for any other changes.

3. Send the feedback to an agent

Open Notes to review your feedback. Choose the receiving agent if the viewer asks, then send the notes. When the agent publishes an update, open the new version and check the changes.

Share the artifact

Use the artifact’s sharing control to grant access. See Share a resource. Export a copy when you need to keep it outside Firetower.

Artifact or preview?

An artifact is a saved result. A preview is a running application in a workspace.
