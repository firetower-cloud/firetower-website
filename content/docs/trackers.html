Before you start

Issues from a connected git host need no separate token. For Linear, create a personal API key from its API settings. The steps below show Linear.

Screenshots show the desktop app with sample data.

1. Connect the tracker

Open Tasks → Trackers. Paste your Linear key into API key, then select Connect. The get one link opens Linear’s key settings.

2. Check the connection

Wait for connected. Firetower shows the teams available to that key. If it fails, check that the key is valid and has access to the intended Linear workspace.

3. Choose an issue

Return to Tasks. Choose Linear from the tracker picker, then narrow the list by team or status. Select Start beside an issue.

4. Review and start the work

Firetower fills in the issue context. Choose the repository, worker machine and agent profile. Adjust the request if needed, then use the send button to start.

Starting from an issue preserves its source link. Updates to the issue’s status depend on your tracker’s git integration and team workflow.
