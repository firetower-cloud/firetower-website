Before you start

You need administrator access to Firetower and the URL of your company’s git instance. For browser sign-in, you also need permission to register an OAuth application on that instance.

Screenshots show the desktop app with sample data.

Open Repositories → Git hosts in the desktop app. The Add a host button starts the setup.

1. Choose the provider

Open Repositories → Git hosts → Add a host. Choose your provider. For a private instance, choose its self-hosted option.

2. Set the address and sign-in method

Enter the instance URL. Firetower checks it and shows the supported sign-in method. Give it a name your team will recognize.

For browser sign-in, register an OAuth application using the instructions shown. Paste its client ID or application ID. If you cannot register one, select the token option; each person will connect with their own token.

3. Add the host

Select Add the host. The instance appears under Git hosts. Firetower may immediately offer to connect your own account.

Each team member can now select Connect and sign in with their own identity. Adding a host does not grant access to its repositories.
