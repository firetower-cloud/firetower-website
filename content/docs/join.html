Open the desktop app. This is where you enter the Firetower domain provided by your administrator.

Before you start

  • Get your Firetower URL and sign-in details from an administrator.
  • Connect to your company VPN if the installation is private.
  • Use macOS or Windows for the desktop app. iOS and Android are available for mobile access.

Connect from your computer

  1. Open your Firetower URL in a browser. Sign in. Replace a temporary password when prompted.
  2. Download the desktop app from the installation’s download page. Choose macOS or Windows. Install and open it.
  3. Enter the same Firetower URL in the app. Complete sign-in with your own account.
  4. Check access. Open Machines and check that a machine is available to you. Connect an agent account, or use one your team has shared.
Expected result

The app opens your company’s installation. An empty workspace list is normal on your first visit.

If you cannot connect

What you see What to check
Server cannot be reached Open the same URL in a browser on this device. Check the VPN and the hostname.
Sign-in rejected Use your Firetower credentials, not your GitHub or agent account. Ask an administrator to reset your password if needed.
No machines available Ask for access to a shared machine. Administrators must add a worker before anyone can run work.
