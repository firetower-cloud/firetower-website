Before you start

Use a separate worker machine running macOS, Linux or Linux inside WSL2. Enable SSH and make sure the control plane can reach it.

Prepare an SSH account with the file and network access your agents need. Keep it separate from your control-plane server.

Screenshots show the desktop app with sample data.

1. Open Machines

In the desktop app, select Machines in the sidebar. Select Add a machine to open the connection form.

2. Enter the machine details

Enter the worker’s address, SSH account and a recognizable name in the connection form.

3. Authorize Firetower’s SSH key

Copy the public key shown in the app. Add it to the worker account’s ~/.ssh/authorized_keys, or register it through your cloud provider.

The expandable instructions show the command to use. Return to the app and select Add it. Firetower checks the SSH connection.

4. Install the worker

Once SSH connects, select Install the worker. Keep the app open while Firetower installs it and reconnects.

5. Install your agents

Choose the agents this machine should run. Select Install Claude Code, Install Codex or another available agent. Wait for the checkmarks, then select Done.

6. Check readiness in the app

Expand the machine’s row. Look for Ready, green checks for SSH, the worker and required tools, and an installed agent under Agents.

If a check fails, follow the remedy shown in the app, then select check again. System packages that require administrator access must be installed on the worker by its operator.
