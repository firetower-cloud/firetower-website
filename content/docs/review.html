Recommended: track the work in a draft PR

For GitHub projects, ask your lead agent to use the gh CLI to create a draft pull request and keep it updated as the team works. Have the agents record progress, checks and review findings there. Firetower also lets you inspect the diff and ship changes from the app.

Example request
Use gh to open a draft PR for this task.
Keep it updated with changes, checks and findings from every agent.
Leave it as a draft until I have reviewed it.

Open the workspace, then select Diff in the right panel to inspect changed files.

Review the work

  1. Read the agent’s summary. Compare the result with the original request.
  2. Inspect the changed files. Check for unrelated edits, sensitive data and behavior changes.
  3. Verify the checks. Review test results and rerun anything needed in the workspace.
  4. Request revisions. Keep the feedback concrete and review the updated diff.

Ship through your git host

Use the workspace’s shipping flow to create or update a pull request or merge request. Your connected git identity needs permission to push and create the request. Complete code review and merge through your team’s normal process.

If shipping fails

  • Check whether your git token expired or lost repository access.
  • Check write permissions and provider token scopes.
  • Resolve branch conflicts before retrying.
  • Confirm you are acting in your own agent conversation.

Work without a repository? Download the result instead of using a git shipping flow.
