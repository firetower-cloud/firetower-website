Before you start

Add a worker and install the agent you want to use. Have your subscription sign-in ready.

Screenshots show the desktop app with sample data.

1. Choose your agent

Open Customize → Agents. Expand the agent, then select Connect an account. If an account is already connected, select Connect another account.

2. Sign in to your subscription

Give the connection a clear name, such as Engineering · Primary. Follow the sign-in method shown for your agent.

Claude Code

Run claude setup-token on your own computer. Sign in with the intended Claude account, paste the resulting token into Firetower, then select Connect account.

Connecting Codex instead

Name the account and select Continue to sign in.

Open the displayed sign-in address. Enter the code and approve access with the intended Codex account. Return to Firetower and wait for Account connected.

3. Choose the default

At Account connected, check the identity. Leave Use by default for new work selected if this should be your usual account, then select Done.

4. Check the saved connection

The account now appears under the agent. Confirm it says Connected. New work can use this account; existing runs keep their current account.
