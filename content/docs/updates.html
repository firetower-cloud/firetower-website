Open Updates from the account menu. Start by checking for updates, then update the control plane, workers and app in that order.

Check for updates

Click Check again to refresh the available versions. The screenshot highlights this button. Version numbers are examples; yours will depend on the current release.

Before proceeding, read the release notes and create a backup. Keep the matching root key and deployment configuration.

1. Update the control plane

In This Firetower, click Upgrade to…. This opens the plan for the control plane.

Review the proposed file changes and any required environment variables. Keep your edited configuration unless you intend to replace it. Then click Start the upgrade.

Follow the run until it succeeds and the control plane is reachable again. Resolve a failed step before updating workers.

2. Update the workers

Let running tasks finish, or stop them deliberately after saving their outputs. A worker update restarts its execution environment. Do not interrupt work you need to keep.

Select the machines to update, then click Plan the update for…. Workers are updated to the control-plane version.

Keep Wait until nothing is running selected. Click Start the upgrade; Firetower waits for the selected workers to become idle. If you choose not to wait, affected sessions will end.

Check that every selected worker reconnects after the update.

3. Update the app

In the desktop app, find This app. Click Update to… and relaunch. Save any unsent message first; the desktop window will restart.

This app’s update control appears in the desktop client. For mobile, install the available update through your app distribution channel.
