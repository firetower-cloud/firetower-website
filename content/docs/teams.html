Start in Customize → Agent profiles. Agent teams are configured through the profiles that do and delegate the work.

Create the specialists

Create an Operator profile for each responsibility. A small team might have an Implementer, a Reviewer and a QA specialist. Give each a clear output and the skills it needs.

Create the lead

  1. Create a Manager profile. Enable delegation.
  2. Choose the profiles it can delegate to. Keep the allowed set focused on the work.
  3. Write the coordination instructions. Say what to delegate, what results to collect and when to ask you for a decision.
  4. Choose each specialist’s placement. Shared files suit review and coordinated edits; separate workspaces suit independent changes.
  5. Launch a task with the Manager profile. Follow delegated work and its returned results in the conversation.
Example: manager instructions 
Implement the requested change.
Ask Reviewer to inspect the diff and QA to check the behavior.
Resolve their findings and summarize the results.
Ask before expanding the scope of the task.

Review the team’s output

The lead receives specialist results, but you still review changes and permission requests. Separate branches may need integration before shipping.

Two meanings of “team”

An agent team is a group of profiles working together. A company team is a group of people used for access control. Manage company membership in the administration site.
