Agent, model and account

Agent / harness
The software that uses a model and tools to do work. Claude Code and Codex are examples. The harness manages the conversation and tool execution.
Model
The AI model the agent uses. Available models and controls depend on the selected agent.
Agent account
The connected subscription or API credential that authorizes usage. Sharing an account shares its allowance.

Profile, skill and team

Agent profile
Saved instructions and defaults for a job, such as Code reviewer. It can select an agent, account, skills and execution settings.
Skill
Reusable instructions and supporting files for a specific task. For example, a review checklist can be used by several profiles.
Agent team
A lead and the specialist profiles it can delegate to. A Manager can delegate; an Operator does its assigned work.

Profiles and skills are optional. A profile defines the role; a skill supplies a reusable method. Neither is a running agent until work starts.
