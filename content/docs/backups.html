Open Updates from the account menu as an administrator. You can create a database backup directly from the app.

1. Create a backup

Click Back up now below the Machines list. Keep the page open while it shows Backing up….

2. Check completion

The button changes to Backed up when the request succeeds. The dump is saved on the server; it is not downloaded to your device.

3. Keep the rest of the recovery set

The in-app backup contains the database’s public schema. Keep these items as well:

SettingWhat it does
Matching root keyRequired to decrypt saved credentials. Store a protected copy separately from the database dump.
Deployment configurationYour domains, environment settings and service configuration.
Worker filesUncommitted changes and non-git outputs you need to keep. These are not in the server database.

The server keeps the ten most recent dumps. Keep off-server copies under your team’s retention policy.

Test recovery

Test the complete recovery set in an isolated environment. Follow Restore and recover.
